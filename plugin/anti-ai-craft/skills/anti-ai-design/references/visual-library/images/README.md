# Redistributable visual assets

All 100 main-catalog references are versioned here. Every file has an explicit redistribution basis, a source URL, license identifier, dimensions, SHA-256 digest, perceptual hash, and completed validation record in `../catalog.jsonl`.

The product subdirectories are storage boundaries, not style presets. Do not load them wholesale or infer that open-source licensing makes a product's branding reusable.

See [ATTRIBUTIONS.md](../ATTRIBUTIONS.md) and `../LICENSES/` for credit and license texts. Trademark rights are not granted and inclusion does not imply endorsement.

Permission-unclear products were removed from the public catalog. Their earlier research is summarized in `../research/superseded-link-only-summary.jsonl`; no corresponding image files are versioned.
