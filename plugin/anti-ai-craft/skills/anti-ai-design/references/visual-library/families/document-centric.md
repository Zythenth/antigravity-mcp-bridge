# Document-centric

Interfaces where a persistent written or structured artifact is the primary object and surrounding controls serve its authorship, reading, or provenance.

**Usually appropriate for:** Writing, notes, knowledge bases, specifications, collaborative documents, and research collections.

**Frequent errors:** Fragmenting the artifact into dashboard widgets; letting chrome dominate the document; hiding provenance or document state.

**Do not use by default for:** Rapid monitoring, high-volume comparison, or workflows whose core object is a graph, timeline, or queue.

**Products represented:** Apache Superset, Documenso, Element, Godot, Kdenlive, Mattermost, Nextcloud.
