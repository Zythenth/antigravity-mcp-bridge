# Technical / developer

Evidence-rich surfaces for building, inspecting, diagnosing, comparing, and operating software or other technical systems.

**Usually appropriate for:** Code, diffs, logs, debugging, observability, deployment, schemas, and generated-artifact inspection.

**Frequent errors:** Showing summaries without evidence; using terminal aesthetics as decoration; disconnecting state from the artifact it affects.

**Do not use by default for:** General audiences that do not share the underlying model or lightweight tasks that need plain-language guidance.

**Products represented:** Blender, Documenso, GIMP, GitHub, Godot, Penpot, Visual Studio Code.

This is a textual index. Open only the source or local image for the few references selected for the current task.
