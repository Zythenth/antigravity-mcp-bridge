# Minimal / utilitarian

Focused surfaces with deliberately few controls because the task, state, or object model is genuinely narrow.

**Usually appropriate for:** Settings, quick actions, lightweight utilities, focused retrieval, and constrained single-purpose workflows.

**Frequent errors:** Removing essential context; mistaking emptiness for quality; hiding infrequent but critical actions.

**Do not use by default for:** Complex comparison, multi-stage operations, or domains whose exceptions and relationships must remain visible.

**Products represented:** Grafana, Immich, Mattermost, Nextcloud, OpenShot.
