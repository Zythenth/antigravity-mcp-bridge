# Command / keyboard-first

Surfaces organized around fast retrieval and execution of named actions, often with shortcuts, ranking, and recent context.

**Usually appropriate for:** Expert navigation, global actions, launchers, command palettes, and repeated workflows where recall beats browsing.

**Frequent errors:** Making commands undiscoverable; using a palette as the only path; mixing destructive and safe actions without cues.

**Do not use by default for:** Infrequent consumer tasks, touch-first flows, or situations where users cannot know the available vocabulary.

**Products represented:** Immich, Kdenlive, KiCad, Visual Studio Code, Zulip, darktable.
