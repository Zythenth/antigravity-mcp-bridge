# Expressive / playful

Interfaces whose tone, composition, motion, or customization supports exploration, identity, delight, or creative ownership.

**Usually appropriate for:** Personalization, creative exploration, expressive consumer tools, playful onboarding, and culturally specific products.

**Frequent errors:** Adding decoration unrelated to action; sacrificing legibility; assuming asymmetry or novelty is inherently human.

**Do not use by default for:** Safety-critical work, dense regulated operations, or contexts where visual surprise interferes with predictable control.

**Products represented:** Excalidraw, FreeCAD, GIMP, Immich, OpenShot, Zulip, darktable.
