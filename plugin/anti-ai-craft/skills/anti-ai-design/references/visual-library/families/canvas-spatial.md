# Canvas / spatial

Interfaces where position, scale, connection, sequence, or direct manipulation carries domain meaning.

**Usually appropriate for:** Design, node graphs, timelines, maps, diagrams, media sequencing, and prototypes.

**Frequent errors:** Treating the canvas as decoration; hiding selection context; omitting inspectors, coordinates, or navigational anchors.

**Do not use by default for:** Linear forms, simple records, and tasks where spatial freedom adds ambiguity rather than expressive power.

**Products represented:** Blender, Excalidraw, FreeCAD, GitHub, Mattermost, OpenShot, Penpot.
