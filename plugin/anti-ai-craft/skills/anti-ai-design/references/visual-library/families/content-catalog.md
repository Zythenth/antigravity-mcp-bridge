# Content / catalog

Browse and retrieval surfaces where recognizable items, provenance, filtering, and collection structure matter more than global metrics.

**Usually appropriate for:** Libraries, marketplaces, media collections, research blocks, assets, products, and discovery.

**Frequent errors:** Using identical cards for heterogeneous media; hiding filters; relying on imagery when comparison needs aligned attributes.

**Do not use by default for:** Operational queues, detailed editing, and homogeneous numeric records better expressed as tables or lists.

**Products represented:** GIMP, Godot, Kdenlive, Mattermost, Penpot, darktable.
