# Dense professional

High-information work surfaces where aligned comparison, status, hierarchy, and frequent action justify visible density.

**Usually appropriate for:** Operational queues, CRMs, issue tracking, search, analytics, review, and administration with many comparable objects.

**Frequent errors:** Adding density without hierarchy; replacing evidence with KPI cards; exposing every secondary action permanently.

**Do not use by default for:** Small collections, calm reading, promotional surfaces, or novice workflows that do not benefit from simultaneous context.

**Products represented:** Actual Budget, Documenso, GitHub, Grafana, KiCad, Nextcloud, Zulip, darktable.

This is a textual index. Open only the source or local image for the few references selected for the current task.
